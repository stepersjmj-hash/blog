# 📸 사진 메타데이터 기반 AI 블로그 생성기

사진을 업로드하면 EXIF에서 촬영 날짜·위치를 자동 추출하고, 평점과 감상평을 입력하면 AI가 블로그 글을 작성해주는 단일 HTML 페이지입니다.

## 실행 방법

`index.html` 파일을 더블클릭하거나 브라우저로 열기만 하면 됩니다. 별도 서버나 설치 불필요.

## 주요 기능

- **사진 업로드**: 드래그앤드롭 또는 클릭으로 여러 장 업로드
- **EXIF 자동 추출**: 촬영일시, GPS 좌표, 카메라 정보
- **위치 자동 변환**: GPS 좌표 → 한글 지명 (OpenStreetMap Nominatim 무료 API)
- **감상 입력**: 제목, 5점 별점, 한줄 감상, 상세 메모
- **블로그 스타일 4종**:
  - 🟢 **네이버 블로그 최적화** (SEO + 지도 + 해시태그) — 기본값
  - 여행일기 (감성적), 리뷰형 (정보 중심), SNS형 (짧고 캐주얼)
- **두 가지 AI 모드**:
  - **API 자동 생성**: Anthropic API 키 입력 → Claude가 바로 작성
  - **프롬프트 복사**: 완성된 프롬프트를 복사 → Claude/ChatGPT에 붙여넣기
- **결과 저장**: 클립보드 복사, Markdown(.md), HTML(.html) 다운로드 (HTML은 이미지 임베드)

## 네이버 블로그 최적화 기능

스타일을 "네이버 블로그 최적화"로 선택하면 다음이 자동 적용됩니다:

- **SEO 최적화 글 구조**: 1500자 이상, 소제목 H2 활용, 키워드 자연스러운 반복
- **주요 키워드 입력란**: 검색 노출에 활용할 키워드를 직접 지정 (비우면 AI가 자동 추출)
- **네이버 지도 자동 첨부 박스**: GPS 좌표를 가진 사진에서 네이버 지도 검색 URL을 자동 생성
- **장소 정보 박스**: 글 말미에 장소명/주소/방문일/평점 자동 정리
- **해시태그 자동 생성**: 위치·카테고리·분위기 기반 5-10개
- **"텍스트만 복사" 버튼**: 네이버 블로그 에디터에 깔끔하게 붙여넣을 수 있도록 Markdown 문법을 제거하고 사진/지도 위치 마커로 변환
- **발행 가이드**: 결과 화면에 네이버 블로그 단계별 가이드 표시

## 네이버 블로그 발행 흐름

1. 스타일을 "네이버 블로그 최적화"로 선택
2. 생성된 블로그에서 "텍스트만 복사" 버튼 클릭
3. 네이버 블로그 에디터에 붙여넣기
4. `[📷 사진N 첨부]` 표시 위치에 사진을 순서대로 첨부
5. `[🗺️ 여기에 네이버 지도 첨부]` 표시 위치에서 에디터 상단 "지도" 버튼으로 장소 검색 후 삽입
6. 해시태그를 발행 전 태그 입력란에도 동일하게 입력 (검색 노출 향상)

## 사용 흐름

1. 사진을 드래그앤드롭으로 업로드
2. 자동으로 EXIF에서 날짜·위치 정보가 표시됨
3. 평점, 한줄 감상, 상세 메모 입력
4. 블로그 스타일 선택 (여행일기/리뷰/SNS)
5. AI 모드 선택:
   - **API 모드**: Anthropic 콘솔에서 키 발급 → 입력 → "블로그 생성"
   - **프롬프트 모드**: "블로그 생성" 누르면 프롬프트가 클립보드에 복사됨 → AI에 붙여넣기
6. 결과를 복사하거나 .md / .html 파일로 다운로드

## 기술 스택

- 순수 HTML/CSS/JavaScript (프레임워크 없음)
- [exifr](https://github.com/MikeKovarik/exifr) (CDN) - EXIF 메타데이터 추출
- [OpenStreetMap Nominatim](https://nominatim.org/) - 역지오코딩 (무료, 키 불필요)
- [Anthropic API](https://docs.claude.com/) - Claude Sonnet 4.5 모델 호출 (옵션)

## 주의사항 / 한계

- **API 키는 메모리에만 저장**: 새로고침하면 다시 입력 필요 (localStorage 미사용으로 보안 강화)
- **Nominatim 사용량 제한**: 초당 1회 제한이 있어 다량 업로드 시 위치 변환이 느려질 수 있음
- **GPS 없는 사진**: EXIF에 GPS가 없으면 위치 정보는 비어있음 (메모에 직접 적어주세요)
- **브라우저 CORS**: Anthropic API 직접 호출은 `anthropic-dangerous-direct-browser-access` 헤더로 활성화. 프로덕션 환경에서는 서버 프록시 권장
- **간이 Markdown 렌더러**: 제목, 강조, 이미지, 리스트만 지원. 표나 코드블록은 미지원
- **이미지 placeholder**: AI가 `![](사진1)`, `![](사진2)` 형식으로 배치하면 자동으로 실제 이미지로 치환됨
- **네이버 블로그 직접 자동 포스팅 불가**: 네이버는 공식 외부 포스팅 API를 제공하지 않음. 본 도구는 "복사 → 붙여넣기" 워크플로우 최적화에 집중
- **네이버 지도 이미지 직접 임베드 불가**: NCP Static Map API는 헤더 인증 방식이라 브라우저에서 직접 호출 불가 (CORS). 대신 네이버 지도 검색 URL 링크로 대체하고, 발행 시 에디터의 "지도" 버튼 사용 권장
- **네이버 스마트에디터 컴포넌트**: 인용구/글감 박스 등은 HTML 붙여넣기로 들어가지 않음. 발행 후 직접 추가 필요
