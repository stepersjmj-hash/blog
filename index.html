📸 사진 메타데이터 → AI 블로그 생성기

사진을 올리면 EXIF에서 날짜·위치를 자동 추출하고, 평점과 감상평으로 AI가 블로그 글을 만들어드립니다.

1. 사진 업로드

📷 사진을 끌어다 놓거나 클릭해서 선택

JPG/HEIC 등 EXIF가 포함된 이미지 권장

2. 감상 입력

★★★★★

네이버 SEO에 활용되는 키워드입니다. 비워두면 위치/메모 기반으로 AI가 자동 생성.

3. AI 생성 방식

🤖 API 자동 생성
📋 프롬프트 복사

키는 브라우저 메모리에만 저장됩니다 (새로고침 시 사라짐).
발급: console.anthropic.com

API 키 없이 사용. 완성된 프롬프트를 복사해 Claude/ChatGPT에 붙여넣으세요.

📝 생성된 블로그

왼쪽에서 사진을 올리고 감상을 입력한 뒤
"블로그 생성"을 눌러주세요.

🟢 네이버 블로그 발행 가이드

  1. "텍스트만 복사" 버튼으로 본문 복사 → 네이버 블로그 에디터에 붙여넣기
  2. 업로드한 사진을 순서대로 에디터에 따로 첨부 (placeholder 위치 참고)
  3. 지도 첨부 위치에서 에디터 상단 "지도" 버튼 클릭 → 장소 검색 후 삽입
  4. 발행 시 태그는 자동 생성된 해시태그를 별도 태그 입력란에도 입력 (검색 노출 향상)
  5. 주제 분류는 글 내용에 맞게 선택 (맛집, 국내여행, 일상 등)
